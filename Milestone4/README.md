# Milestone 4 — MoodMentor

## AI-Based Employee Wellness Management Platform

MoodMentor is an AI-powered employee wellness management platform designed to help employees understand, track, and improve their emotional wellness.

## Features

- User registration and login
- Email OTP verification
- Password recovery
- JWT authentication
- Secure password hashing
- Mood tracking
- NLP-based sentiment analysis
- Emotion detection
- Personalized recommendations
- Wellness questionnaire
- Personal mood analytics
- Employee wellness analytics
- PDF reports
- CSV exports
- Profile management
- FastAPI backend
- Streamlit frontend
- PostgreSQL / Neon database

## Technology Stack

- Python
- Streamlit
- FastAPI
- PostgreSQL
- Neon
- JWT
- bcrypt
- spaCy
- VADER Sentiment
- Transformers
- Pandas
- Matplotlib
- Seaborn
- ReportLab

## Security

Sensitive credentials must never be committed to GitHub.

Environment variables are used for database credentials, JWT secrets, SMTP credentials, and backend configuration.
